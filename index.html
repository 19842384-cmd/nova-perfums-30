Nuestra identidad

Más que un perfume, una expresión de ti.

NOVA PERFUMS es una marca conceptual dedicada a la presentación de fragancias modernas y elegantes. Buscamos que cada persona encuentre un aroma que represente su estilo y sus recuerdos.

Público objetivo: jóvenes y adultos interesados en la perfumería, el cuidado personal y los detalles elegantes.

Propuesta de valor: presentar diferentes estilos de fragancias en una experiencia de compra visual, sencilla y agradable.

Misión

Ofrecer una experiencia digital atractiva para descubrir fragancias que acompañen la personalidad de cada cliente.

Visión

Convertirnos en una marca reconocida por su identidad elegante, su creatividad y su atención al cliente.

Tecnologías web

Estas tecnologías ayudan a construir y publicar nuestro sitio.

HTML

Define la estructura de una página: títulos, imágenes, botones y secciones.

CSS

Controla los colores, tamaños, espacios, tipografías y el diseño visual.

JavaScript

Agrega interactividad, responde a los clics y permite cambiar el idioma. 

button.addEventListener("click", () => {
  alert("¡Bienvenido a NOVA!");
});

jQuery

Es una biblioteca de JavaScript que simplifica algunas tareas y animaciones. 

$("#mensaje").fadeIn();

JSON

Es un formato de texto para organizar e intercambiar datos. Aquí se usa para guardar las traducciones. 

{
  "marca": "NOVA PERFUMS",
  "precio": 45
}

Hosting y dominios

El hosting permite publicar los archivos de la página. Un dominio es su dirección, por ejemplo, ejemplo.com.

DNS conecta el nombre del dominio con el servidor correspondiente. La actualización puede tardar un tiempo en reflejarse.
